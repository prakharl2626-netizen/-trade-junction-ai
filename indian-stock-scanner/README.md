# ⚡ Trade Junction AI - Indian Stock Market Scanner & Trading Terminal

Institutional-grade real-time AI Stock Scanner & Options Terminal for NSE/BSE Indian markets.

## 🚀 Features
- 📊 Real-time NSE/BSE Live Exchange Feed (Nifty 50, Bank Nifty, Sensex, 50+ Top Stocks)
- 🤖 Multi-Indicator Confluence Score /100 (EMA 9/21, RSI 14, MACD, VWAP, Supertrend, Volume)
- 🟢 Buy / 🔴 Sell / 🟡 Watch Actionable Trade Plans (Entry, SL, T1, T2)
- ⚡ F&O Options Scanner (PCR, Max Pain Strike, CE/PE Momentum Calls)
- 🧠 Anthropic Claude 3.5 Sonnet Integration
- 🔒 Secure Username & Password Authentication Gatekeeper

## 💻 How to Run Locally
```bash
python server.py
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
